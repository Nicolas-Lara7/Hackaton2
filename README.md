## Cómo ejecutar
Requisitos: Node 24 LTS.

```bash
npm install
cp .env.example .env   # si no existe .env
npm run dev
```

Variable de entorno:

```txt
VITE_API_BASE_URL=https://logpose-api-jg7f.onrender.com/api/v1
```

Build de producción: `npm run build`.
